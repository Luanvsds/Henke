# Recursos visuais

Recursos reaproveitados dos arquivos enviados para o projeto Henke. Não foi acrescentada uma licença de código aberto ao conjunto.

| Arquivo | Uso |
| --- | --- |
| `assets/images/henke-01.png` | Ícone da página extraído do HTML original |
| `assets/images/henke-02.jpg` | Fundo e textura do hero no desktop |
| `assets/images/henke-03.jpg` | Fundo e textura do hero no celular |
| `assets/images/henke-04.png` | Logo horizontal original do hero |
| `assets/images/image-1.jpg` a `image-4.jpg` | Fotos ilustrativas da seção de conforto |
| `assets/images/image-5.jpg` | Foto ilustrativa dos serviços |
| `assets/images/image-6.jpg` | Foto ilustrativa da seção sobre a Henke |
| `assets/images/image-7.png` | Logo de reserva no rodapé; o JavaScript aplica o logo do hero |
| `assets/images/pmoc-arquitetura.webp` | Foto arquitetônica ilustrativa do arquivo Canvas Visual enviado |
| `assets/fonts/*.woff2` | Manrope e Instrument Serif, extraídas das referências enviadas |

Os arquivos de imagem extraídos de Base64 mantêm os mesmos bytes; seus hashes estão em `asset-checksums.json`. Os nomes das fontes foram preservados para manter a correspondência com as declarações de `fonts.css`.
