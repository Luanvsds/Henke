# Conferência da organização

- HTML sem blocos CSS, JavaScript ou estilos inline.
- Referências de CSS, scripts, fontes e imagens conferidas na pasta.
- Sintaxe dos quatro arquivos JavaScript verificada com Node.
- Código do efeito do hero idêntico ao script da versão aprovada; somente a configuração dos caminhos das imagens foi externalizada e resolvida em relação ao HTML.
- Imagens extraídas de Base64 sem recompressão.
- Revisão visual do hero e do PMOC via servidor local em subpasta.
- Simulador: dois aparelhos de 9–18 mil BTU e um de 22–30 mil BTU resultam em R$ 62,70 por mês e R$ 752,40 ao ano.
- Nenhuma imagem quebrada ou transbordamento horizontal na revisão desktop.

Limite desta conferência: WebGL 1 estava desabilitado no navegador de teste. O fundo alternativo foi conferido, mas a animação WebGL não pôde ser exercitada nesse ambiente. A lógica original permanece inalterada.
